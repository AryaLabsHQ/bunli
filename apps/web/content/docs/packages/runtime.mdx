`@bunli/runtime` provides terminal runtime wiring extracted from `@bunli/tui`. It contains the event system, transport types, and renderer options used by Bunli's interactive terminal features.

<Callout type="info">
  For UI components and hooks, see [`@bunli/tui`](/docs/packages/tui). Import render/prompt APIs from explicit subpaths like `@bunli/runtime/prompt`.
</Callout>

## Installation

```bash
bun add @bunli/runtime
```

## Event System

`@bunli/runtime` provides a typed event system for runtime observability:

### Event Types

```typescript
import type {
  RuntimeRendererStartedEvent,
  RuntimeRendererMissingRenderEvent,
  RuntimeRendererDestroyedEvent,
  RuntimeImageRenderAttemptEvent,
  RuntimeImageRenderResultEvent,
  RuntimePromptStartedEvent,
  RuntimePromptCancelledEvent,
  RuntimeTransportErrorEvent,
  RuntimeEvent,
  RuntimeEventType,
} from "@bunli/runtime";
```

**Renderer Events:**

- `RuntimeRendererStartedEvent` — Renderer has started
- `RuntimeRendererMissingRenderEvent` — Render function not provided
- `RuntimeRendererDestroyedEvent` — Renderer was destroyed
- `RuntimeImageRenderAttemptEvent` — Image render was attempted
- `RuntimeImageRenderResultEvent` — Image render completed

**Prompt Events:**

- `RuntimePromptStartedEvent` — Prompt session started
- `RuntimePromptCancelledEvent` — Prompt was cancelled

**Transport Events:**

- `RuntimeTransportErrorEvent` — Transport layer error occurred

### Event Schema

All events are validated via Zod schemas:

```typescript
import { RuntimeRendererStartedEventSchema } from "@bunli/runtime";

// Validate an event
const event = RuntimeRendererStartedEventSchema.parse({
  type: "runtime.renderer.started",
  timestamp: Date.now(),
  bufferMode: "alternate",
});
```

## Transport System

### `RuntimeTransport`

The transport interface for runtime communication:

```typescript
import type { RuntimeTransport, RuntimeTransportObserver } from "@bunli/runtime";
```

**Interface:**

```typescript
interface RuntimeTransport {
  /** Send data through the transport */
  send(data: unknown): void;

  /** Subscribe to transport events */
  subscribe(observer: RuntimeTransportObserver): void;

  /** Close the transport */
  close(): void;
}
```

### `RuntimeTransportObserver`

Observer for transport events:

```typescript
interface RuntimeTransportObserver {
  onSend?(data: unknown): void;
  onError?(error: Error): void;
  onClose?(): void;
}
```

## Renderer Options

### `TuiRenderOptions`

Options for TUI rendering:

```typescript
import type { TuiRenderOptions } from "@bunli/runtime";
```

**Properties:**

| Property | Type | Default | Description |
|----------|------|---------|-------------|
| `exitOnCtrlC` | `boolean` | `true` | Exit on Ctrl+C |
| `targetFps` | `number` | `30` | Target frames per second |
| `enableMouseMovement` | `boolean` | `true` | Enable mouse movement tracking |
| `useMouse` | `boolean` | `false` | Enable mouse interaction |
| `bufferMode` | `"alternate" \| "standard"` | `"standard"` | Terminal buffer mode |
| `[key: string]` | `unknown` | — | Additional options |

### `OpenTuiRendererOptions`

Resolved renderer options:

```typescript
import type { OpenTuiRendererOptions } from "@bunli/runtime";
```

**Properties:**

| Property | Type | Description |
|----------|------|-------------|
| `exitOnCtrlC` | `boolean` | Exit on Ctrl+C |
| `targetFps` | `number` | Target frames per second |
| `enableMouseMovement` | `boolean` | Enable mouse movement tracking |
| `useMouse` | `boolean` | Enable mouse interaction |
| `useAlternateScreen` | `boolean` | Use alternate screen buffer |
| `bufferMode` | `"alternate" \| "standard"` | Terminal buffer mode |

## Usage

### Observing Renderer Events

```typescript
import { createPlugin } from "@bunli/core/plugin";
import type { RuntimeEventType } from "@bunli/runtime";

export const runtimeDebugPlugin = createPlugin({
  name: "runtime-debug",
  setup(context) {
    context.logger.info("Runtime debug plugin initialized");
  },
  beforeCommand(context) {
    // Log runtime events
    context.logger.debug(`Command: ${context.command}`);
  },
});
```

### Custom Transport

```typescript
import type { RuntimeTransport, RuntimeTransportObserver } from "@bunli/runtime";

class MyTransport implements RuntimeTransport {
  send(data: unknown) {
    // Send data
  }

  subscribe(observer: RuntimeTransportObserver) {
    // Subscribe to events
  }

  close() {
    // Close transport
  }
}
```

## Subpath Imports

For specific functionality, import from explicit subpaths:

```typescript
// Renderer options
import type { TuiRenderOptions } from "@bunli/runtime/options";

// Events
import type { RuntimeEvent } from "@bunli/runtime/events";

// Transport
import type { RuntimeTransport } from "@bunli/runtime/transport";

// Prompt (includes prompt runtime primitives)
import { prompt } from "@bunli/runtime/prompt";
```

<Callout type="warning">
  The root export (`@bunli/runtime`) is intentionally minimal. Use explicit subpath imports for specific APIs.
</Callout>
