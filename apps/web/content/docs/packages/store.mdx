`@bunli/store` provides a typed file-backed persistence layer for CLI applications. It offers Zod-like field definitions with automatic validation, JSON persistence, and seamless integration with Bunli's plugin system.

## Installation

```bash
bun add @bunli/store
```

## Quick Start

```typescript
import { createStore } from "@bunli/store";

// Define your store schema
const configStore = createStore({
  path: "./.mycli",
  fields: {
    apiKey: { type: "string" },
    debug: { type: "boolean", default: false },
    maxRetries: { type: "number", default: 3 },
    allowedHosts: { type: "string", array: true },
  },
});

// Read values
const apiKey = configStore.get("apiKey");
const debug = configStore.get("debug");

// Update values
configStore.update({ apiKey: "new-key", debug: true });
```

## API

### `createStore`

Creates a typed store instance.

```typescript
function createStore<TFields extends FieldsDef>(
  options: StoreOptions<TFields>
): StoreInstance<TFields>
```

**Parameters:**

| Parameter | Type | Description |
|-----------|------|-------------|
| `options` | `StoreOptions<TFields>` | Store configuration including path and field definitions |

**Returns:** A `StoreInstance<TFields>` with `get`, `update`, and `reset` methods.

### StoreInstance

```typescript
interface StoreInstance<TFields extends FieldsDef> {
  /** Get a field value */
  get<K extends keyof TFields>(key: K): InferStoreConfig<TFields>[K];

  /** Get all field values */
  getAll(): InferStoreConfig<TFields>;

  /** Update one or more fields */
  update(updates: Partial<InferStoreConfig<TFields>>): void;

  /** Reset all fields to defaults */
  reset(): void;

  /** Field definitions */
  fields: TFields;

  /** Store file path */
  path: string;
}
```

## Field Types

### Scalar Fields

```typescript
// String field
{ type: "string" }

// String with default
{ type: "string", default: "hello" }

// Number field
{ type: "number" }

// Boolean field
{ type: "boolean", default: false }
```

### Array Fields

```typescript
// Array of strings
{ type: "string", array: true }

// Array with default
{ type: "string", array: true, default: ["a", "b"] }

// Array of numbers
{ type: "number", array: true }

// Array of booleans
{ type: "boolean", array: true }
```

### Field Options

| Option | Type | Description |
|--------|------|-------------|
| `type` | `"string" \| "number" \| "boolean"` | Field value type |
| `array` | `boolean` | Whether field is an array |
| `default` | `T \| readonly T[]` | Default value |
| `description` | `string` | Human-readable description |
| `validate` | `(value: T) => void \| Promise<void>` | Custom validation function |

## Error Handling

`@bunli/store` throws typed errors for different failure scenarios:

```typescript
import {
  StoreReadError,
  StoreWriteError,
  StoreParseError,
  StoreValidationError,
} from "@bunli/store";

try {
  configStore.update({ apiKey: "new-key" });
} catch (error) {
  if (error instanceof StoreReadError) {
    console.error("Failed to read store file");
  } else if (error instanceof StoreWriteError) {
    console.error("Failed to write store file");
  } else if (error instanceof StoreParseError) {
    console.error("Store file is corrupted");
  } else if (error instanceof StoreValidationError) {
    console.error("Invalid field value");
  }
}
```

## Usage with Plugins

Stores integrate with Bunli's plugin system for sharing state:

```typescript
import { createPlugin } from "@bunli/core/plugin";
import { createStore } from "@bunli/store";

const configStore = createStore({
  path: "./.mycli",
  fields: {
    verbose: { type: "boolean", default: false },
  },
});

export const configPlugin = createPlugin({
  name: "config",
  store: { configStore },
  setup(context) {
    // Access store via plugin store
    const verbose = context.store.configStore.get("verbose");
  },
});
```

<Callout type="info">
  Store instances are immutable after creation. To change the storage path or fields, create a new store instance.
</Callout>

## Type Utilities

### `InferStoreConfig<TFields>`

Extract the inferred configuration type from field definitions:

```typescript
import type { InferStoreConfig, FieldsDef } from "@bunli/store";

type MyConfig = InferStoreConfig<{
  apiKey: { type: "string" };
  debug: { type: "boolean" };
}>;

// Results in:
// { apiKey: string; debug: boolean }
```

### `FieldDef`

The base field definition interface:

```typescript
interface FieldDef<V> {
  description?: string;
  validate?: (value: V) => void | Promise<void>;
}
```

### `FieldsDef`

A record of field definitions:

```typescript
type FieldsDef = Record<string, FieldDef>;
```

### `ValueType`

The supported value types:

```typescript
type ValueType = "string" | "number" | "boolean";
```
