`@bunli/tui` provides OpenTUI React components and UI primitives for building rich terminal interfaces in Bunli CLI applications.

## Installation

```bash
bun add @bunli/tui
```

## Overview

`@bunli/tui` re-exports components from [`@opentui/react`](https://www.npmjs.com/package/@opentui/react) and [`@opentui/core`](https://www.npmjs.com/package/@opentui/core), plus provides Bunli-specific utilities.

<Callout type="info">
  For runtime primitives (events, transport, renderer options), see [`@bunli/runtime`](/docs/packages/runtime).
</Callout>

## Components

Import components from subpaths:

```typescript
import { Button, Text, Box } from "@bunli/tui/components";
```

## Hooks

`@bunli/tui` exports hooks from `@opentui/react`:

```typescript
import {
  useKeyboard,
  useRenderer,
  useTerminalDimensions,
  useTimeline,
  useOnResize,
} from "@bunli/tui";
```

### `useKeyboard`

Handle keyboard events:

```typescript
const { key, meta } = useKeyboard();

if (key === "c" && meta) {
  // Ctrl+C pressed
}
```

### `useRenderer`

Access the renderer instance:

```typescript
const renderer = useRenderer();

renderer.onDraw((frame) => {
  // Custom rendering
});
```

### `useTerminalDimensions`

Get current terminal dimensions:

```typescript
const { width, height } = useTerminalDimensions();

console.log(`Terminal: ${width}x${height}`);
```

### `useTimeline`

Animation timeline control:

```typescript
const timeline = useTimeline();

timeline.play();
timeline.pause();
timeline.seek(0);
```

### `useOnResize`

Handle terminal resize events:

```typescript
useOnResize((dimensions) => {
  console.log(`New size: ${dimensions.width}x${dimensions.height}`);
});
```

## Styling

Import text styling utilities from `@opentui/core`:

```typescript
import { bold, fg, italic, t, TextAttributes } from "@bunli/tui";

// Basic styling
console.log(bold("This is bold"));
console.log(fg("red", "This is red text"));
console.log(italic("This is italic"));

// Combined styling
const styled = t("Hello", [
  bold,
  fg("cyan"),
]);
```

### `TextAttributes`

The `TextAttributes` type represents styling attributes:

```typescript
type TextAttributes = (
  | { type: "bold" }
  | { type: "italic" }
  | { type: "fg"; color: string }
  | { type: "bg"; color: string }
  | { type: "dim" }
)[];
```

```typescript

const option: SelectOption<string> = {

  description: "Optional description",
```

Keyboard event type:

```typescript
import type { KeyEvent } from "@bunli/tui";

const handleKeyEvent = (event: KeyEvent) => {
  if (event.key === "Enter") {
    // Handle Enter
  }
};
```

Configuration for CLI rendering:

```typescript
import type { CliRendererConfig } from "@bunli/tui";

const config: CliRendererConfig = {
  bufferMode: "standard",
  targetFps: 30,
};
```

## Sync Batcher

`createSyncBatcher` creates a batched updater for high-frequency updates:

```typescript
import { createSyncBatcher } from "@bunli/tui";

const batch = createSyncBatcher({
  onUpdate: (state) => {
    // Apply batched update
  },
});

// Queue updates (batched)
batch.update({ count: 1 });
batch.update({ count: 2 });
batch.update({ count: 3 });

// Flush pending updates
batch.flush();
```

**Options:**

| Option | Type | Description |
|--------|------|-------------|
| `onUpdate` | `(state: T) => void` | Callback when updates are flushed |
| `schedule` | `number` | Schedule delay in ms (default: 16) |

## Usage with Bunli

```typescript
import { createCLI } from "@bunli/core";
import { useRenderer, useTerminalDimensions } from "@bunli/tui";
import { defineCommand, option } from "@bunli/core";
import { z } from "zod";

const cli = await createCLI({
  name: "my-cli",
  commands: [
    defineCommand({
      name: "ui",
      options: {
        bufferMode: option(z.enum(["standard", "alternate"])),
      },
      render: async ({ flags, useTimeline }) => {
        const timeline = useTimeline();
        const { width, height } = useTerminalDimensions();

        return {
          draw(frame) {
            frame.box(0, 0, width, height, { title: "My CLI" });
          },
        };
      },
    }),
  ],
});

cli.run();
```
